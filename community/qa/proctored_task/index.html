Practical QA Assignment

Test the QACommunity Login Page

Assignment Objective

Test the actual QACommunity login page and demonstrate your ability to observe, think, document, and explain your testing decisions.

Do not submit only theoretical definitions. You must perform practical testing and record your actual observations.

Instructions

  1. Choose your own username.
  2. Calculate the expected password based on the login rule.
  3. Try to log in using different valid and invalid inputs.
  4. Record what actually happens for each test.
  5. Identify at least one unexpected behavior, usability issue, or possible improvement.
  6. Explain why you selected that issue as important.
  7. Suggest one practical solution for the issue.

Minimum Tests to Perform

  • Correct username and correct password
  • Correct username and incorrect password
  • Empty username
  • Empty password
  • Username containing spaces

You may perform additional tests if you notice other possible issues or interesting behavior.

Test Result Format

Test Scenario: Test Data: Expected Result: Actual Result: Pass/Fail: Reason:

Submission Requirements

  • Screenshot of one successful test
  • Screenshot of one failed test
  • Five test scenarios
  • One completed test case
  • One bug report
  • A short explanation of your most important finding

Questions to Answer

  1. What did you test first, and why?
  2. Which test was the most important?
  3. What problem did you find?
  4. How would you improve the login page?
  5. What additional test would you perform if you had more time?

Important Requirement

Each participant must use a different username and include their username in the submission. Answers that only contain general definitions without actual testing evidence may not be accepted.

AI tools may be used for formatting or language improvement, but the screenshots, test results, observations, and reasoning must be based on your own testing.
